## Scope requiring further refinement

- Existing matrix sheets require the supplied conversion tool and reviewed ID mapping; app Import handles normalized CSV/XLSX. It does not silently resolve same-name members.
- Export service is separated from screen filters and can be extended for Google Sheets; direct Google Sheets Export is not implemented.
- YouTube video oEmbed title lookup has a manual fallback for playlists/unavailable metadata. Playlist URLs are registered as archive entries; playlist item counts are not fetched without a YouTube API integration.
- Screen modules are split into shared UI, public, member, admin, administration forms and operational tools.
