## Import contract

Upload .xlsx/.csv (max 5 MB, max 2,000 normalized rows per batch). Workbook UI selects a tab and header row. Map columns to documented canonical fields. Matrix sheets first use the transformation script / mapping template; they are not treated as flat tables. Download a template for each entity. Name-only foreign keys are rejected: provide member_id/event_id (look up in admin exports) or an explicitly reviewed ID mapping. UUIDs preserve identity through name changes. Preserve external_id for idempotency. Original input is stored in restricted import batch data for review, not in public storage.

Phone: remove separators, +82 → leading 0; Korean mobile format 01[016789] + 7–8 digits. Missing/invalid numbers fail. Dates: ISO or clearly structured YYYY.MM.DD; impossible values fail; ambiguous local dates/Excel serials require explicit conversion. Historical verification records must include explicit payment/actual flags. No speculative repairs.

Preview shows new/merge/error counts; errors block commit. Preview batch is owned by requesting admin, expires after one hour and cannot be edited by client at commit. Atomic DB import RPC revalidates current admin role, takes an advisory transaction lock, validates foreign keys and upserts by stable keys. A repeat commit returns existing result. Back up and test on staging first. Production import must be explicitly confirmed inside the app.

## Outstanding policy decisions

Source privacy notice says only “일정 기간”; exact retention/deletion periods and operator privacy contact must be set before accepting production applications. Guest rules mention invite-only/max 3 lifetime visits; this is distinct from the forbidden event capacity/waitlist. Current app displays the published rule and leaves exception review to admins; it implements no capacity, waitlist or auto-promotion.
