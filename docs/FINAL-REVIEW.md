## 데이터 이전

관리자 → 더보기 → Import에서 Excel/CSV, 시트/헤더 선택, 열 매핑, 신규/병합/오류 건수, 명시적 확정을 지원한다. 변경 후에도 에러가 있는 배치는 DB에 반영하지 않는다. 실패한 새 파일을 올리면 이전 파일의 미리보기/확정 상태를 지운다.

전화번호를 정규화하여 동일 인물을 확인하며, 같은 파일의 중복 전화번호·게스트/운동·회원/회비월·회칙 분류도 거절한다. 명확한 연월일 형식은 ISO 날짜로 바꾸고, 모호한 미국/유럽 날짜와 Excel 숫자 일련번호는 임의 해석하지 않는다. 기존 관리자 메모도 회원 매핑 대상으로 제공한다.

권장 순서: 회원/게스트 기본정보·운동 일정 → 생성된 UUID 확인 → 신청/회비/출석/유니폼 → 회칙 검토·게시. 가로형 회비·출석원본과 두 영역의 회원명단은 `scripts/transform-workbook.mjs`와 검토한 매핑을 사용한다. 출석부의 연간 합계만으로 과거 운동별 출석을 만들어내지 않는다. 상세 원본 대응은 `MIGRATION.md`를 따른다. 실제 운영 원본 파일은 이번 검수에서 가져오거나 Import하지 않았다.

## 실제 계정 및 남은 의존성

테스트 회원/관리자 이메일은 소유자가 제공한 주소를 사용하고 공개 저장소에 기록하지 않는다. 초대 토큰 검증 후 비밀번호 설정 화면으로 이동하는 흐름을 지원한다. 초대만으로 회원/관리자 권한을 만들지 않는다. 비밀번호 설정 및 첫 로그인은 계정 소유자가 수행한다. 게스트 흐름은 비로그인이다.

실제 관리자 권한 부여는 대상 계정을 확인한 뒤 수행하며, 운영 데이터와 섞일 수 있는 테스트 일정/회원은 명확한 테스트 이름을 붙인다. 검수 후 삭제는 별도 확인 없이 자동 수행하지 않는다.

Vercel Hobby의 매일 04:00 UTC Cron은 정각 실행을 보장하지 않는다. 기존 `supabase/schedule-roster.sql`은 정각 실행을 위한 선택 설정이다. CRON_SECRET/VAPID/실제 예약 실행 및 기기 Push 수신은 설치·동작을 별도 확인해야 한다. 기존 데이터 마이그레이션은 원본·백업·매핑 검토가 선행되어야 한다.
