# Authentication

SpotLight email/password sign-in, account signup and recovery: `src/app/api/auth/[action]/route.ts`. UI: `src/components/club/auth.tsx`. Email confirmation/recovery token verification and legacy PKCE compatibility: `src/app/auth/`. No Google sign-in is offered or initiated. Supabase Auth owns password storage; member/application tables never receive credentials. Request-scoped verified SSR sessions: `src/lib/supabase/server.ts` and `src/proxy.ts`. Approval/roles/RLS are unchanged. Auth signup does not create or activate a member. See the root README for Email Provider/SMTP/templates and manual first-admin setup. Vercel deployment protection is separate from application authentication.
